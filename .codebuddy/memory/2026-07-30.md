## 完善右键 New 菜单显示 .datachart 文件

### 新增问题
右键 New 菜单中没有 DataChart 文件类型选项。

### 根因
1. **`getDefaultExtension()` 返回值与注册的扩展名不一致**
   - `plugin.xml` 中 `extensions="datachart"` (全小写)
   - `getDefaultExtension()` 返回 `DataChart.LANGUAGE_NAME` = `"dataChart"` (大小写不一致)
   - 导致文件类型与模板关联失败

2. **中文文件名可能导致加载问题**
   - 模板文件名 `DataChart 图形文件.datachart.ft` 含中文+空格

### 修复
- 新增 `DataToolsFileType.EXTENSION = "datachart"` 常量统一管理扩展名
- `getDefaultExtension()` 返回 `EXTENSION` 常量
- `DataChartEditorProvider.accept()` 也改用常量
- 模板文件名改为 ASCII：`DataChart.datachart.ft`
- `plugin.xml` 中 `<internalFileTemplate name="DataChart"/>`
- 保留中文 `getDisplayName()`/`getDescription()` 用于菜单显示

## 7-31 修复：ClassNotFoundException

- **根因**：源码是 `.java` 文件却放在 `src/main/kotlin/` 目录，Gradle Java 插件不编译该目录 → `build/classes` 为空
- **修复**：用户已将文件移至 `src/main/java/`

## 7-31 修复：工具栏间距与分隔线

- 用户 UI：工具栏与图表区无间距、无分隔线
- `.form` 文件 `matte` border 类型不被支持（`UnexpectedFormElementException: unknown type: matte`）
- **方案**：`.form` 中设置 margin（6/8/6/8），Java 代码中 `headerTool.setBorder(new MatteBorder(0,0,1,0, JBColor.border()))` 添加分隔线
- **踩坑**：`.form` 的 margin + Java EmptyBorder 会双重内边距，二者只能选其一；`JBColor.border()` 适配深/浅色主题
