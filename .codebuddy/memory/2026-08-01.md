## 需求：搜索框 + 表格内搜索高亮 + 键盘导航

### 用户反馈
- 搜索框（顶部 SearchTextField）太长，希望缩短
- 输入文本后回车，在下面的 KanbanBoard 表格中搜索
- 命中要高亮显示
- 通过键盘上下键在搜索结果中切换

### 实现

**1. 搜索框缩短（DataChartView.form）**
- preferred-size width 从 200 改为 120
- 加 maximum-size width=180 防止被 GridLayoutManager 撑开
- hsize-policy 从 6 改为 2（不再疯狂占满）

**2. KanbanCard 新增搜索高亮机制**
- 新增字段：
  - `searchMatchedRows: Set<Integer>` - 所有命中行
  - `searchFocusRow: int = -1` - 焦点行
  - `isSearchFocusCard: boolean` - 焦点卡片（表头命中时整个卡片作为视觉锚点）
- 新增方法：
  - `getSearchMatchedRows() / setSearchMatchedRows() / clearSearchMatchedRows()`
  - `setSearchFocusRow(int) / getSearchFocusRow()`
  - `setSearchFocusCard(boolean) / isSearchFocusCard()`
- 新增颜色常量：
  - `SEARCH_HIGHLIGHT_COLOR = #FFF3B0`（淡黄，普通命中）
  - `SEARCH_HIGHLIGHT_FOCUS_COLOR = #FFD24A`（深黄，焦点行 / 焦点卡片边框）
- `drawTableCard` / `drawChartCard` 的边框逻辑加入 `isSearchFocusCard` 判断
- 行高亮优先级：用户选中(橙) > 搜索焦点行(深黄) > 搜索命中行(淡黄) > 连线占用(线色)
- 提升 `ROW_HEIGHT = 18` 为 public 常量，统一替换 5 处硬编码

**3. KanbanBoard 搜索核心逻辑**
- 新增内部类 `SearchResult(cardId, rowIndex)`：
  - rowIndex = -1 表示表头命中
  - rowIndex >= 0 表示列索引
- 新增字段：
  - `searchResults: List<SearchResult>`
  - `searchFocusIndex: int = -1`
- 新增方法：
  - `search(String keyword)` - 遍历所有卡片，匹配 表名/表注释/列名/列注释（不区分大小写子串）
  - `clearSearch()` - 清空所有搜索状态
  - `getSearchResultCount() / getSearchFocusIndex()`
  - `focusNextSearchResult() / focusPrevSearchResult()` - 上下导航，循环切换
  - `applySearchFocus()` - 把焦点写入对应卡片
  - `scrollToFocusResult()` - 平移 transform 让焦点行落到视口中心
  - `removeSearchResultsForCard(cardId)` - 删除卡片时同步清理

**4. DataChartView 搜索框交互**
- 给 `searchTextField.getTextEditor()` 加 KeyListener：
  - `VK_DOWN` → focusNextSearchResult + updateStatus
  - `VK_UP` → focusPrevSearchResult + updateStatus
  - `VK_ESCAPE` → 清空搜索文本 + clearSearch
- 复用 `zoomPercentLabel` 显示状态："100% | 3/12"（当前/总数），无结果时恢复纯百分比
- `loadFromJson` 加载文件后清空搜索状态

### 关键设计
- **行高常量提到 public**：避免 5 处硬编码 18 散落各处
- **搜索状态独立色系**：不与用户选中（橙）、连线占用色（线色 palette）冲突
- **复用 zoomPercentLabel 显示状态**：不新增组件，避免动 .form
- **删除卡片同步搜索结果**：避免 stale cardId 导致 focusNext 跳转异常

## 需求：Focus 按钮 + FullScreen 切换 + Zoom 实时显示

### 用户反馈
- 如果图移到看不到或偏了，点击 focusButton 把图移到居中展示
- FullScream = 进入全屏模式；进入后按钮变 ExitFullScream + exit_fullScream 图标，点击退出
- 最左边的 100% 显示当前 zoom 倍率，比如 150%

### 实现

**1. KanbanBoard 新增 focusView()**
- 计算所有卡片 bounds 合并矩形的中心（画板坐标）
- 视口中心（屏幕坐标）
- 反推 transform 的 translate，让内容中心落到视口中心
- **保留当前 zoomFactor**，只调 transform
- 与 `resetView()` 区分：reset = zoom=100% + transform 清零；focus = 保留 zoom、居中显示
- 无卡片时不改变视图

**2. KanbanBoard 新增 viewChangeListener**
- 字段：`Runnable viewChangeListener`
- 触发时机：`zoom()` / `panByWheel()` / `mouseDragged 画板拖拽` / `resetView()` / `focusView()`
- 公开 `setViewChangeListener(Runnable)` 注册
- 与现有 `scrollToFocusResult()` 内部已有 `notifyViewChanged` 触发器衔接

**3. DataChartView 接入**
- `initKanbanBoard` 中注册 `setViewChangeListener(this::updateSearchStatusLabel)`
- 新增 `setupToolBarButtons()`：focusButton 点击 → `kanbanBoard.focusView()`；fullScreamButton 点击 → `toggleFullScreen()`
- `focusButton.setIcon(PluginIcons.reset)` + setText("Focus") + tooltip

**4. 全屏切换实现**
- `toggleFullScreen()` 翻转 `isFullScreen`
- `enterFullScreen()`：用 `hiddenOnFullScreen: List<Component>` 记录并隐藏 searchTextField/focusButton/exportPDFButton/exportPictureButton/zoomPercentLabel
- fullScreamButton icon: fullScream → exit_fullScream，文字 FullScream → ExitFullScream，tooltip 翻转
- `exitFullScreen()`：批量恢复所有隐藏组件 + 按钮外观恢复
- 调 `rootPanel.revalidate() + repaint()` 触发重排

**5. zoomPercentLabel 实时显示**
- `getZoomPercentText()` 改为实时读 `kanbanBoard.getZoomFactor()`，不再依赖 label 旧值
- `(int) Math.round(zoomFactor * 100) + "%"`
- viewChangeListener 驱动刷新，搜索/zoom/pan 任何变化都更新

### 关键设计
- **focusView vs resetView**：前者保留 zoom，后者完全复位（用 100% zoom + 居中），用不同按钮承载
- **viewChangeListener 统一驱动**：zoom/pan/reset/focus/search 共享一个刷新入口，DataChartView 不用在每个 KanbanBoard 入口散落监听
- **getZoomPercentText 实时读取 zoomFactor**：避免 zoomPercentLabel 旧值与实际 zoom 漂移

### 编译
`./gradlew compileJava` BUILD SUCCESSFUL，0 新增 lint 警告

## 需求：导出 PDF / 图片（参考 DataHelper/DragableBoard）

### 用户反馈
- 点击 Export PDF / Export Picture → 弹文件保存对话框
- 选择位置，保存
- 默认文件名 = 当前 .datachart 文件名 + 日期（如 `schema_20260801_153012.pdf`）

### 实现

**1. KanbanBoard 导出核心（参考 DataHelper/DragableBoard）**
- 新增 iText 5.5.13 + iText Asian 5.2.0 imports
- `calculateTotalBounds()`：所有 cards 合并包围盒 + 40px padding（无 cards 时 fallback 画板大小）
- `paintForExport(Graphics2D, Rectangle2D, boolean dark)`：导出共用的绘制入口
  - 画背景（不透明，避免 PDF 透明）
  - `g2.translate(-minX, -minY)` 把卡片相对位置平移到 (0, 0)
  - 画网格 + 连线 + 卡片（与 paintComponent 共享 highlight 逻辑）
  - **不画**屏幕坐标的对齐辅助线 / tooltip / 鼠标连线预览
- `exportToPdf(File)`：iText Document + PdfWriter + DefaultFontMapper（中文用 STSong-Light → simsun → 默认）
- `exportToImage(File, String format, double scale)`：JPG 用 JPEGImageWriteParam 0.95f 压缩；PNG 用 TYPE_INT_ARGB；超内存自动降级 scale
- 内存管理：estimatedBytes > freeMemory*0.6 时 safetyScale 降级

**2. DataChartView 工具栏按钮**
- `setupToolBarButtons` 加 `exportPDFButton` / `exportPictureButton` 监听
- `exportAsPdf()` / `exportAsImage()`：
  - 空画板先给 Info 通知，不弹文件框
  - `JFileChooser` + `FileNameExtensionFilter`
  - 默认文件名 `generateDefaultFileName(ext)` = baseFileName + "_" + yyyyMMdd_HHmmss + "." + ext
  - 用户没写后缀时自动补 .pdf / .jpg
  - 成功/失败用 `Notifications.Bus.notify(Notification)` 通知

**3. DataChartEditor 暴露文件名**
- 新增 `resolveBaseFileName()`：`file.getNameWithoutExtension()`，fallback "datachart"
- `ensureInitialized` 中 `dataView.setBaseFileName(resolveBaseFileName())` 注入
- `DataChartView` 新增 `setBaseFileName(name)` / `getBaseFileName()`

### 关键设计
- **复用 paintForExport**：PDF/Image 共用一份绘制逻辑，避免两份 paintComponent 走偏
- **画板坐标平移到输出 (0,0)**：`g2.translate(-minX, -minY)` 让输出文件自然从 (0,0) 开始排版
- **默认文件名去后缀**：`getNameWithoutExtension()`，避免 `xxx.datachart_20260801_xxx.pdf` 叠加
- **内存管理自动降级 scale**：避免大画板导出 OOM，参考 DataHelper 经验
- **空画板早返回**：先给通知不弹文件框，提升交互反馈感

### 编译
`./gradlew compileJava` BUILD SUCCESSFUL，0 新增 lint 警告
