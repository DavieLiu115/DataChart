## Text Tab 的 JSON 格式化
用户反馈"text 是 json，可以按照 json 格式化么"（原 `JSON.toJSONString(data)` 是紧凑单行）。

- 新增 `com.wd.model.ChartJsonUtil`：`toPrettyJson(Object)`（保存用）/ `prettifyText(String)`（旧文件迁移用，非法 JSON 返回 null）。
- 三处后处理（缺一不可，详见 DEVELOPMENT_GUIDE 第 50 节补充）：
  ① fastjson PrettyFormat 的 `\t` → 2 空格（与模板 fileTemplates/DataChart.datachart.ft 一致）；
  ② 键值冒号后补空格（`"k": v`，与模板 / IDEA Ctrl+Alt+L 风格一致，否则互相打架）；
  ③ `parseObject(raw, Feature.OrderedField)` —— fastjson 的 JSONObject 默认 HashMap，不加会打乱字段顺序
      → 每次打开都判"需重排"而反复写盘、顺序抖动。
- `DataChartView.serializeToJson()` 改走 `toPrettyJson`；`DataChartEditor.prettifyFileIfNeeded()` 在加载完成后
  把磁盘上的紧凑 JSON 自动重排（只改空白；Text Tab 有未保存修改时跳过；`pretty.equals(raw)` 则跳过 → 幂等）。
- jshell 实测：2 空格缩进、`"key": value`、字符串值内冒号不受影响、字段顺序保持、`IDEMPOTENT=true`。
- `./gradlew compileJava` 通过、0 警告。

## 去掉重复的第二个 "Text" Tab（`Board | Text | Text`）
- 现象：打开 .datachart 有三个 Tab（中间那个是要去掉的）。
- 根因：**`FileEditorPolicy.HIDE_DEFAULT_EDITOR` 挡不住平台文本编辑器** ——
  反编译 `FileEditorProviderManagerImpl.postProcessResult` 确认它的谓词是
  `it is DefaultPlatformFileEditorProvider`（只移除"默认编辑器"这一个）；
  多的那个 "Text" 来自独立 EP 注册的 `PsiAwareTextEditorProvider`
  （`META-INF/LangExtensions.xml`：`id="text-editor" order="first"`，继承 `TextEditorProvider`），
  对所有非二进制文件都 accept。
- 解法：`FileEditorProviderSuppressor`（EP `com.intellij.fileEditorProviderSuppressor`）——
  它的 `isSuppressed(Project, VirtualFile, FileEditorProvider)` **带 project/file 参数**，
  可以只对 .datachart 抑制 `instanceof TextEditorProvider`，不影响其它文件。
  新增 `com.wd.editor.DataChartTextEditorSuppressor` + plugin.xml 注册。
  ⚠️ EP 是全局注册的，实现里必须自己按文件类型过滤。
- 副作用（无害）：`.datachart` 不再有平台 Document → `EditorFileSync.writeContent` 的 Document 同步分支
  与 `prettifyFileIfNeeded` 的 `isDocumentUnsaved` 检查自然跳过，保留作为兜底。
- `./gradlew compileJava` 通过、0 警告。
