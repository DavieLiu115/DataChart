## .datachart 编辑器改为双 Tab：图形（Board）+ Text（参考 PYYP）
用户要求"第一个展示图，第二个展示文本"，并指定参考 `/Users/lww/IdeaProjects/PYYP`。

- PYYP 已有成熟模式（`.bizx` 的 `EosFlowEditorProvider` / `.datasetx` 的 `EosDatasetEditorProvider`）：
  `FileEditorPolicy.PLACE_BEFORE_DEFAULT_EDITOR` + `EosEditorFileSync` + `EosSaveAllHook`，tab 名 "Flow" / "Text"。
- 本次搬到 DataChart：
  - `DataChartEditorProvider`：`HIDE_DEFAULT_EDITOR` → `PLACE_BEFORE_DEFAULT_EDITOR`（默认激活图形 Tab，Text 由平台提供）。
  - `DataChartEditor.getName()` → i18n `DataChart.editor.tab.board`（英文 Board / 中文 看板）。
  - 新增 `com.wd.editor.EditorFileSync`：VFS_CHANGES 监听（外部改动 → 无修改静默刷新 / 有修改弹窗询问）+ `writeContent` 双写 VFS/Document + 撤销栈隔离。
  - 新增 `com.wd.editor.EditorSaveAllHook`：`FileDocumentManagerListener.beforeAllDocumentsSaving` 补位保存画布。
  - `DataChartEditor` 保存改走 `writeContent`；新增 `reloadFromDisk()`；dispose 释放同步器。
- 三个关键坑（详见 DEVELOPMENT_GUIDE 第 50 节）：
  ① 只 `setBinaryContent` 不刷新 Text Tab 的 Document → 内置 SaveAll 会拿旧 Document 覆盖新内容；
  ② 程序性保存必须关撤销记录，否则 Cmd+Z 抢走画布撤销且会把内容倒回旧版本；

  → 保留调用 + `@SuppressWarnings("deprecation")`（按第 49 节的四步决策）。
- `build.gradle.kts` 加了 `-Xlint:deprecation`（可见具体文件:行号，本次靠它定位到 UndoConstants）。

## Text Tab 的 JSON 格式化
用户反馈"text 是 json，可以按照 json 格式化么"（原 `JSON.toJSONString(data)` 是紧凑单行）。

- 新增 `com.wd.model.ChartJsonUtil`：`toPrettyJson(Object)`（保存用）/ `prettifyText(String)`（旧文件迁移用，非法 JSON 返回 null）。
- 三处后处理（缺一不可，详见 DEVELOPMENT_GUIDE 第 50 节补充）：
  ① fastjson PrettyFormat 的 `\t` → 2 空格（与模板 fileTemplates/DataChart.datachart.ft 一致）；
  ② 键值冒号后补空格（`"k": v`，与模板 / IDEA Ctrl+Alt+L 风格一致，否则互相打架）；
  ③ `parseObject(raw, Feature.OrderedField)` —— fastjson 的 JSONObject 默认 HashMap，不加会打乱字段顺序
      → 每次打开都判"需重排"而反复写盘、顺序抖动。
- `DataChartView.serializeToJson()` 改走 `toPrettyJson`；`DataChartEditor.prettifyFileIfNeeded()` 在加载完成后
  把磁盘上的紧凑 JSON 自动重排（只改空白；Text Tab 有未保存修改时跳过；`pretty.equals(raw)` 则跳过 → 幂等）。
- jshell 实测：2 空格缩进、`"key": value`、字符串值内冒号不受影响、字段顺序保持、`IDEMPOTENT=true`。
- `./gradlew compileJava` 通过、0 警告。
