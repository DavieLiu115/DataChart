## 7-31 二次修复：菜单 hover 白字 + 列行左/右半分流

### 用户反馈
1. 表头右键无论左半/右半，菜单项应是同一个"复制表名 / 复制注释"
2. 列行右键：左半（列名+类型）弹菜单；右半（注释）走连线模式
3. 菜单项 hover 时白字看不清（Swing 默认 L&F 在 IntelliJ 主题下问题）

### 修复
- **`showHeaderContextMenu`**：移除 isLeftHalf 参数，统一两项菜单（复制表名/复制注释）
- **`showColumnContextMenu`** 调用前在 `mousePressed` 用 `KanbanCard.getColumnNameRightX(rowIndex)` 判断左/右半
  - 左半 → 弹菜单
  - 右半 → 进入连线模式（`connectionSource`/`isConnecting`）
- **新增 `KanbanCard.getColumnNameRightX(rowIndex)`**：返回列名 + " : " + 类型文字的右端 x
- **新增 `buildStyledPopupMenu()` / `buildStyledMenuItem()`**：
  - 用 `JBColor.foreground()` / `JBColor.background()` 显式设置前景/背景
  - 通过 `putClientProperty("MenuItem.selectionForeground", ...)` 让 L&F 在 hover/selected 时也用主题前景色
- **`showConnectionContextMenu`** + **`addRelationTypeItem`** 同步应用 styled 主题
- 编译通过

### 关键教训
- Swing L&F 在 IntelliJ 主题下，JPopupMenu 的 hover/selected 前景色默认是白色，背景看 L&F → 白字白底。必须显式设置 `MenuItem.selectionForeground` client property。
- 列行用 `getColumnNameRightX` 做左右半 hit test，比单纯按"中线"更准确（按实际内容边界）
- 替换大段方法时注意 `replace_in_file` 必须匹配完整块，否则会残留旧代码产生编译错误（这次出了 89 个错）
