# 2026-09-16

## DataChart 看板连线终点高亮（方案演变）
- 用户最初反馈：一对一连线终点（目标行）没有高亮标识。第一版方案是在终点画实心圆点（`Connection.drawEndpointDot()`），**用户否决了圆点方案**，要求改为"落到哪一行，哪一行背景颜色变一下"。
- 已回滚圆点方案，`Connection.java` 保留：`resolveLineColor()`（起点行高亮色优先 → 整条线一色）+ 新增公开方法 `getResolvedLineColor()`。
- `KanbanBoard.java`：`computeLinkedRows()` 从 `conn.getColor()` 改为 `conn.getResolvedLineColor()`，起点行高亮时线变橙、终点行背景也同步变橙；并在 `toggleRowSelection()` / `clearActiveHighlight()` 中置 `linkedRowsCache = null` 失效缓存（行高亮变化会改变连线渲染色）。
- 追加需求"连线拖拽时目标行预览高亮（拖到哪行哪行亮）"：新增常量 `CONNECTION_TARGET_PREVIEW_COLOR`（浅色 #BFE8C5 淡绿 / 深色 #33553F 深绿），`mouseDragged` 连线模式中目标行预览高亮从灰色 `CONNECTION_PREVIEW_COLOR` 改为该绿色，与预览线颜色区分；源行仍用灰色。
- 交互约定：连线占用行/终点行背景 = 连线实际渲染色；拖拽预览时源行灰色、目标落点行绿色。
