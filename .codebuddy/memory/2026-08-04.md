## 修复 Win 系统子菜单宽度不够

**问题**：连线右键菜单的"关系类型"子菜单，Win 系统下"一对多/多对多"文字被截断。

**根因**：`BoardContextMenu.FlatCheckBoxMenuItem` 自绘 `paintComponent` 接管渲染后，父类 Swing 的 `BasicMenuItemUI.getPreferredSize()` 依赖 `checkIcon` 计算宽度，但本组件已经关掉了默认 checkIcon → 子菜单宽度按 0 icon 宽算，导致文字被截。

**修复**：重写 `getPreferredSize()`，手动算 `BOX_LEFT_PADDING(18) + BOX_SIZE(14) + 6 + 文字宽度 + 右边距(12)`，高度 `max(BOX_SIZE+8, fm.getHeight()+6)`。

**教训**：自绘 `paintComponent` 接管 Swing JMenuItem/JCheckBoxMenuItem 后，父类 L&F 算 `getPreferredSize()` 不可信，必须自己实现，否则 Win L&F 下子菜单宽度会按 icon=0 算 → 文字截断。

**改动**：
- `src/main/java/com/wd/ui/BoardContextMenu.java` 新增 `FlatCheckBoxMenuItem.getPreferredSize()`
- `DEVELOPMENT_GUIDE.md` 第 29 节追加踩坑记录

## 修复 Win 系统左键不能起手连线

**问题**：Win 系统下从列行按下左键拖动鼠标到终点，松手后不会自动连线，必须右键起手才行。

**根因**：`KanbanBoard.mousePressed` 列行分支只在右键 (`isPopupTrigger || BUTTON3`) 才设置 `isConnecting=true`；左键点击列只调 `toggleRowSelection`（列高亮）。Mac/Win 现代 GUI 默认是左键拖拽，所以左键被"拦截"了。

**修复**：用"待连线状态 + 移动阈值升级"方案，避免破坏原有列高亮交互：
- 新增 `pendingConnectionSource / pendingConnectionSourceRow / pendingConnectionPressPoint` + `CONNECTION_DRAG_THRESHOLD=4`
- `mousePressed` 左键列行：只设 pendingConnection*，不入 `isConnecting`
- `mouseDragged`：pending 状态下计算 `dx²+dy² >= 16` 才升级为 `isConnecting=true`
- `mouseReleased`：pending 未升级就 `toggleRowSelection`（保持原列高亮交互）；升级了就走原有 `addConnection` 逻辑

**改动**：
- `src/main/java/com/wd/ui/KanbanBoard.java` 字段 + 三个 mouse 事件分支
- `DEVELOPMENT_GUIDE.md` 第 30 节追加

**教训**：GUI 拖拽交互的"点击 vs 拖拽"歧义要用阈值延迟判定（移动距离），不能简单根据鼠标按键硬切。左键起手拖拽是现代 GUI 默认，应优先支持。

## 修复连线松手点飘走导致连接丢失

**问题**："鼠标移到 leader 行没点击，点一下别处连接就没了"——拖拽中预览高亮正确显示 leader 行，但松手时鼠标飘到空白处，原 `mouseReleased` 用松手点找 `targetCard`，找不到就不 addConnection，用户视觉上"连接没了"。

**根因**：松手点 ≠ hover 目标。用户在拖拽过程中目标已经选好（leader 行），但松手点飘到别处时 `findCardAt(e.getPoint())` 找不到目标卡片。

**修复**：记录最后一次 hover 的目标，松手优先用：
- 新增 `lastHoverTargetCard / lastHoverTargetRow`
- `mouseDragged` isConnecting 分支命中目标行时写入
- `mouseReleased` 优先用 lastHoverTarget，无效才回退到松手点
- 进入连线时清空 lastHoverTarget（两个入口都清）

**改动**：
- `src/main/java/com/wd/ui/KanbanBoard.java` 字段 + mouseDragged/mouseReleased/mousePressed 三处清理
- `DEVELOPMENT_GUIDE.md` 第 31 节追加

**教训**：拖拽建线场景，松手点是次要的，hover 状态更准确反映用户意图。"最后有效 hover" 应作为建线目标，松手点仅在无 hover 时作为兜底。

## 整理 PDF 导出中文字体回退逻辑

在 `BoardExportUtil` 新增私有静态方法 `createCjkFont(Font)`，把原先内联在 `exportToPdf` 的 `DefaultFontMapper.awtToPdf` 字体回退逻辑抽取出来，供 mapper 调用。优先级：

3. `new DefaultFontMapper().awtToPdf(font)`（都失败回退 AWT 默认）

全部 `NOT_EMBEDDED`。改动：`BoardExportUtil.java` + `DEVELOPMENT_GUIDE.md` 第 32 节。

## 修复连线建线后源行用户选中残留

**问题**：选中 `config_type` 行（橙色）→ 拖到 `invoke_target` 建线 → 点别处后 `invoke_target` 变淡黄，但 `config_type` 仍是橙色——用户期望建线后源行的橙色高亮应被清空。

**根因**：左键列行按下进 pendingConnectionSource → 升级为 isConnecting 时没调 toggleRowSelection，源行 `highlightedRows` 一直保留，导致整条连线 + 源行都是橙色（连线色取自源行高亮色）。

**修复**：
- 新增 `clearUserRowSelection(card, rowIndex)`：从 `getHighlightedRows()` 移除该行；若是 activeHighlight 则 `clearActiveHighlight()`
- `mouseDragged` 升级分支 + `mousePressed` 右键列行起手分支都调 `clearUserRowSelection`
- 快速点击（未升级）仍走原 `toggleRowSelection`，保持 toggle 语义不变

**改动**：`BoardExportUtil.java` + `DEVELOPMENT_GUIDE.md` 第 33 节。
