# 2026-08-20

## 表格卡片高度去掉 400 上限（三轮）
- **第一轮**：去 400 上限（`Math.min → Math.max(..., 400)` 保底）
- **第二轮**（用户要求）：保底也去掉，高度完全由列数决定
- **第三轮**：用户反馈底部 ~22px 空白，根因是 `TABLE_CARD_BASE_HEIGHT = 60`（历史遗留值）≠ `drawTableCard` 实际用到的 `headerHeight(28) + padding(10) = 38`
  - `KanbanCard` 新增 `public static final int HEADER_HEIGHT = 28` / `PADDING = 10`
  - `KanbanBoard.TABLE_CARD_BASE_HEIGHT` 改为 `KanbanCard.HEADER_HEIGHT + KanbanCard.PADDING`（=38）
  - `KanbanCard.updateTableInfo` 改用同样的静态常量，公式三处完全统一
- 教训：**BASE_HEIGHT 与 drawTableCard 公式必须严格对齐**，否则底部留多余空白（38≠60 是隐藏陷阱）
- 已记入 DEVELOPMENT_GUIDE.md 第 39 节

## 拖放表格卡片定位契约改为"鼠标=左上角"
- 用户反馈从 Database 拖表到画板，表格出现位置与松手位置有偏差。
- 原实现"鼠标 = 卡片中心"（`x = boardPoint.x - cardWidth/2`）。
- 改为"鼠标 = 卡片左上角"（`x = boardPoint.x`），符合 draw.io/Freeform 习惯。
- 位置计算只在 `KanbanBoard.addTableCard(info, dropPoint)` 一处，dragOffset 拖动不受影响。
- 已记入 DEVELOPMENT_GUIDE.md 第 40 节。

## 空白拖拽改框选 + 多选 + Command+Del 批量删除
- 需求：表头拖动=移表（原有）；空白拖动=画选区多选表；Command+Del 删除所有选中表。
- `KanbanBoard`：新增 `selectedCards`（LinkedHashSet 多选）、`isSelecting`/`selectionStartBoard`/`selectionRect`（画板坐标）、`SELECTION_DRAG_THRESHOLD=4`。
- 空白按下从 `isDraggingBoard`（平移画板）改为 `isSelecting`（框选）；平移保留滚轮 pan，isDraggingBoard 分支保留不再触发。
- 选中相交判定：`selectionRect.intersects(card.bounds)`；单击空白（<4px）清空选中。
- `selectOnly()`/`clearSelectedCards()` 统一入口；`drawCards` 多选高亮；paintComponent 画半透明蓝选区（注意 `new Color(int,true)` 是 ARGB 会全透明，必须用 `new Color(int)`+composite）。
- `deleteSelectedCard()` 批量删除：先统一连线确认一次，再 `deleteCard(card,false)` 逐张（不重复弹窗）；`deleteCard` 拆出 `confirmRelations` 重载。
- 同步清理点：removeCard / clearCards / loadFromChartData / deleteCard 都加了 `selectedCards` 清理。
- 已记入 DEVELOPMENT_GUIDE.md 第 41 节。
