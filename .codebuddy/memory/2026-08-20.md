# 2026-08-20

## 表格卡片高度去掉 400 上限（三轮）
- **第一轮**：去 400 上限（`Math.min → Math.max(..., 400)` 保底）
- **第二轮**（用户要求）：保底也去掉，高度完全由列数决定
- **第三轮**：用户反馈底部 ~22px 空白，根因是 `TABLE_CARD_BASE_HEIGHT = 60`（历史遗留值）≠ `drawTableCard` 实际用到的 `headerHeight(28) + padding(10) = 38`
  - `KanbanCard` 新增 `public static final int HEADER_HEIGHT = 28` / `PADDING = 10`
  - `KanbanBoard.TABLE_CARD_BASE_HEIGHT` 改为 `KanbanCard.HEADER_HEIGHT + KanbanCard.PADDING`（=38）
  - `KanbanCard.updateTableInfo` 改用同样的静态常量，公式三处完全统一
- 教训：**BASE_HEIGHT 与 drawTableCard 公式必须严格对齐**，否则底部留多余空白（38≠60 是隐藏陷阱）
- 已记入 DEVELOPMENT_GUIDE.md 第 39 节
